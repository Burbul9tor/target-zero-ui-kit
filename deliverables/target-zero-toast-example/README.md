# Target Zero Toast — воспроизводимый пример

Минимальная страница на Vue 3 + Vite для проверки компонента Toast.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://127.0.0.1:5173/`).

## Что проверяется

- пять типов: Neutral, Error, Info, Warning, Success;
- показ с подзаголовком и без него;
- появление Toast справа сверху;
- стек нескольких уведомлений;
- автозакрытие через 4000 ms;
- progress слева направо;
- пауза таймера и progress при наведении;
- ручное закрытие;
- анимации появления и исчезновения.

Полное описание задачи находится в `FRONTEND-TASK-TOAST.md`.
