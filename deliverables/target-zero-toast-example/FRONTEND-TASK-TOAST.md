# Frontend-задача: компонент Toast

## Цель

Реализовать переиспользуемый Toast для Vue 3 по Target Zero Design System и страницу для визуальной и интерактивной проверки.

## Функциональные требования

- Поддержать типы `neutral`, `success`, `info`, `warning`, `error`.
- Обязательный контент — заголовок. Подзаголовок, иконка и progress-индикатор опциональны.
- Публичные параметры: `type`, `title`, `description`, `icon`, `progress`, `showDescription`, `duration`, `autoClose`.
- Значения по умолчанию: `type="neutral"`, `duration=4000`, `icon=true`, `progress=true`, `showDescription=true`, `autoClose=true`.
- Эмитить событие `close` после завершения анимации исчезновения.
- Размещать активные Toast справа сверху с отступом `24px` от viewport.
- Несколько уведомлений собирать в вертикальный стек с интервалом `12px`; каждый Toast имеет независимый таймер.
- Кнопка закрытия завершает показ вручную и запускает ту же exit-анимацию, что и автозакрытие.

## Анимация и таймер

- Появление: `220ms`, fade + slide справа, easing `cubic-bezier(.2, .8, .2, 1)`.
- Исчезновение: `180ms`, fade + slide вправо; удалять элемент из DOM только после анимации.
- Progress высотой `3px` заполняется слева направо за время `duration`.
- По достижении конца progress Toast закрывается.
- При наведении поставить на паузу и CSS-анимацию progress, и фактический JS-таймер.
- После ухода курсора продолжить отсчёт с сохранённого остатка времени.
- Учесть `prefers-reduced-motion`.

## Визуальные требования

- Ширина: `360px`, на узких экранах — не шире доступного viewport.
- Padding: `12px 16px`; внутренний gap: `12px`; radius: `8px`.
- Размер цветного бейджа иконки: `32px`.
- Заголовок: Roboto Medium `14/20`; подзаголовок: Roboto Regular `12/16`.
- Использовать семантические токены Target Zero для фона, текста, иконок и status-цветов.

## Доступность

- Для `warning` и `error` использовать `role="alert"`; для остальных типов — `role="status"`.
- Кнопка закрытия должна иметь `aria-label`.
- Декоративные иконки и progress скрыть от screen reader.
- Управление закрытием доступно с клавиатуры.

## Страница проверки

- Показать все пять вариантов Toast.
- Добавить переключатель «Подзаголовок».
- Рядом с каждым вариантом добавить кнопку «Воспроизвести».
- По нажатию создавать настоящий Toast в правом верхнем углу.
- Разрешить запуск нескольких Toast для проверки стека и независимых таймеров.

## Критерии приёмки

- Все пять типов визуально и семантически различимы.
- Автозакрытие происходит через `4000ms` по умолчанию.
- Progress движется слева направо и синхронизирован с закрытием.
- Наведение действительно останавливает закрытие; после ухода таймер продолжается.
- Ручное и автоматическое закрытие проигрывают exit-анимацию.
- Toast без подзаголовка не оставляет пустого пространства.
- Несколько Toast корректно отображаются стеком.
- Проект проходит typecheck и production build без ошибок.
- Проверено на desktop и при ширине viewport от `320px`.
